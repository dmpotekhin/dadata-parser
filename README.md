## 🎯 Что делает

Скрипт `dadata_okved_filter.py` принимает Excel-файл с организациями и последовательно запрашивает данные у **DaData**, извлекая основной и дополнительные ОКВЭД. Оставляет только те организации, у которых ОКВЭД начинается на **56** или **46**.

### Ключевые возможности:

| Возможность | Описание |
|------------|----------|
| 🔍 **Автоопределение ID** | Сначала пробует ИНН (10/12 цифр), если пустой/невалидный — ОГРН юрлица (13 цифр) или ОГРНИП (15 цифр) |
| ⚖️ **Приоритет настроек** | Флаг `--prefer ogrn` переключает приоритет на ОГРН даже при наличии ИНН |
| 🔄 **Фолбэк** | При `not_found`/`error` по ИНН автоматически повторяет поиск по ОГРН из той же строки (`--fallback-to-ogrn`) |
| 🛡️ **Rate limiting** | Соблюдает лимиты DaData: максимум 30 запросов/мин (скользящее окно 60с) и 10 000 запросов/сутки с автоматическим сохранением прогресса |
| 📁 **Checkpoint система** | Состояние сохраняется в `dadata_state.json` — можноResume с последней позиции |

## 🚀 Быстрый старт

```bash
# 1. Создайте виртуальное окружение
python3 -m venv .venv
source .venv/bin/activate

# 2. Установите зависимости
pip install -r requirements.txt

# 3. Добавьте токен DaData
cp .env.example .env
# Отредактируйте .env и вставьте ваш токен: DADATA_TOKEN=ваш_токен

# 4. Запустите
python3 dadata_okved_filter.py --input список.xlsx --output результат.xlsx --search-by auto --prefer inn
```

## 📦 Установка и настройка

### Токен DaData

Токен **не хранится в коде**. Получите его в личном кабинете [DaData](https://dadata.ru/profile/#info).

Рекомендуемый способ — файл `.env`:

```bash
cp .env.example .env
chmod 600 .env
# Отредактируйте .env и вставьте токен:
# DADATA_TOKEN=ваш_токен
```

### Альтернативы:

| Способ | Команда |
|--------|---------|
| Переменная окружения (Linux/macOS) | `export DADATA_TOKEN="ваш_токен"` |
| Переменная окружения (Windows cmd) | `set DADATA_TOKEN=ваш_токен` |
| Keychain (macOS, безопасный) | `security add-generic-password -a "$USER" -s dadata-token -w 'ваш_токен' -U` |
| CLI с флагом | `python3 dadata_okved_filter.py --token ваш_токен` |

⚠️ **Не рекомендуется:** `--token ваш_токен` — попадает в историю команд и список процессов.

## ⚙️ Параметры командной строки

| Параметр | По умолчанию | Назначение |
|----------|-------------|------------|
| `--input` | — (обязателен) | Входной Excel-файл |
| `--output` | `<input>_dadata.xlsx` | Выходной Excel-файл |
| `--search-by` | `auto` | Режим поиска: `auto` — сам находит колонки ИНН и ОГРН/ОГРНИП |
| `--prefer` | `inn` | Что важнее: `inn` или `ogrn` |
| `--fallback-to-ogrn` | выключен | Повторить поиск по ОГРН после `not_found`/`error` по ИНН |
| `--max-per-minute` | `30` | Максимум запросов в минуту |
| `--daily-limit` | `10000` | Максимум запросов в сутки |
| `--dry-run` | выключен | Показать план без запросов к API |
| `--resume` / `--no-resume` | `--resume` | Пропускать уже обработанные идентификаторы |
| `--okved-prefixes` | `56,46` | Префиксы ОКВЭД через запятую |

Полный список параметров смотрите в файле `README.md` или выполните `python3 dadata_okved_filter.py --help`.

## 🛡️ Защиты и гарантии

- ✅ **Дневной счётчик не сбрасывается случайно** — `--no-resume` пропускает кэш, но не обнуляет суточный учёт
- ✅ **Один писатель на state-файле** — блокировка гарантирует, что два процесса не будут работать одновременно
- ✅ **Excel-формулы в безопасности** — значения, начинающиеся с `=`, `+`, `-`, `@`, `@`, записываются как текст
- ✅ **Идентификаторы не портятся** — колонки читаются как текст, ведущие нули и 15-значные ОГРНИП сохраняются
- ✅ **Строка без валидного идентификатора не тратит лимит** — получает статус `invalid_id`, запрос не отправляется
- ✅ **Токен не утекает** — только `https`; в логах маскируется, в файл попадает лишь признак «токен задан»
- ✅ **Прокси уважаются** — переменные окружения `HTTPS_PROXY`/`HTTP_PROXY`/`NO_PROXY` для внешних адресов
